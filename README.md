# Final Exit
---

## Par spēli

**Final Exit** ir atmosfēriska mīklu spēle, kurā spēlētājam jāizved galvenais varonis cauri līmeņu labirintiem. Lai sasniegtu galamērķi, katrā istabā jābūt vērīgam, tajās ir paslēpti pavedieni, kas palīdzēs salikt kopā četru ciparu kombināciju. Atklājot pareizo kombināciju burvim, būs iespēja atrast pēdējo izeju.

* **Izstrādes dzinējs (Engine):** Godot
* **Mērķauditorija:** Spēlētāji, kuriem patīk atmosfēriskas mīklas
